API Documentation

Integrate with the FarmFinances platform to access agricultural credit evaluation data

Getting Started

The FarmFinances API allows developers to access our agricultural credit evaluation system. This documentation will guide you through the process of integrating with our platform.

Authentication

All API requests require authentication using an API key. You can obtain an API key by registering for a developer account in our portal. 

Authorization: Bearer YOUR_API_KEY

Base URL

All endpoints are relative to the following base URL:

https://api.farmfinances.com/v1

Endpoints

GET /farmers/{farmer_id}

Retrieve detailed information about a farmer, including their credit evaluation.

Parameters

Name Type Required Description
farmer_id string Yes Unique identifier for the farmer
Response
{
  "farmer_id": "f12345",
  "name": "Vijay Shah",
  "location": {
    "district": "Gandhinagar",
    "state": "Gujarat",
    "coordinates": {
      "latitude": 23.2156,
      "longitude": 72.6369
    }
  },
  "credit_score": {
    "traditional_score": 680,
    "farmfinances_score": 742,
    "components": {
      "financial_history": 75,
      "land_productivity": 85,
      "agricultural_practices": 88,
      "climate_resilience": 70
    }
  },
  "farm_data": {
    "total_area": 12.5,
    "soil_health_index": 78,
    "crops": [
      {
        "name": "Wheat",
        "area": 8.2,
        "yield_history": [...]
      },
      {
        "name": "Cotton",
        "area": 4.3,
        "yield_history": [...]
      }
    ]
  }
}
GET /credit-evaluations/{evaluation_id}

Retrieve a specific credit evaluation by its ID.

Parameters

Name Type Required Description
evaluation_id string Yes Unique identifier for the credit evaluation
POST /loan-requests

Create a new loan request for a farmer.

Request Body

{
  "farmer_id": "f12345",
  "amount": 250000,
  "purpose": "Equipment Purchase",
  "term_months": 36,
  "lender_id": "l789"
}
GET /soil-data/{farm_id}

Retrieve soil health data for a specific farm.

GET /weather-data/{location_id}

Retrieve weather forecast and historical data for a specific location.

Webhook Integration

You can set up webhooks to receive real-time updates when a farmer's credit evaluation changes or when new agricultural data is available.

Setting Up Webhooks

Register a webhook URL in your developer dashboard. We will send POST requests to this URL whenever relevant events occur. 

{
  "event": "credit_evaluation.updated",
  "farmer_id": "f12345",
  "previous_score": 720,
  "new_score": 742,
  "timestamp": "2025-03-15T14:32:21Z"
}
